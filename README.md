# Lamonte Link Hub

Website statis sederhana dengan tampilan mirip Linktree untuk fashion anak Lamonte.

## Struktur

- `index.html` - halaman utama dan semua link navigasi.
- `shop/index.html` - halaman Shop untuk retail, promo, reseller, dan WhatsApp CS.
- `styles.css` - styling responsif tanpa framework.

## Aset

- Ilustrasi promo dan mystery box memakai Microsoft Fluent Emoji, lisensi MIT.

## Deploy Gratis di GitHub Pages

1. Upload semua file ke repository GitHub.
2. Buka `Settings` > `Pages`.
3. Pada `Build and deployment`, pilih `Deploy from a branch`.
4. Pilih branch `main` dan folder `/root`.
5. Simpan, lalu akses URL GitHub Pages yang diberikan.

Karena project ini static HTML/CSS, tidak perlu proses build.
